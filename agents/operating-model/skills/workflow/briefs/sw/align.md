# Align the work item

Role: pm.

Read the work item and the repository. Restate the goal in your own words and list the open questions.

## Rules

- Name the user problem and who has it.
- List every assumption you made. Mark each one as confirmed or unconfirmed.
- Ask each open question once, with a recommended default.
- State what is out of scope and why.

## Output

Write the alignment brief as Markdown. Do not write code or tests.
