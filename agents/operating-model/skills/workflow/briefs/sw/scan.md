# Scan for one improvement

Role: improver.

Read the code, the metrics and the run ledger. Find one improvement worth a work item.

## Rules

- Pick one improvement. Name the evidence for it: a metric, a ledger entry, a file and a line.
- State the change in one sentence and the criterion that shows it worked.
- Prefer an improvement that moves a metric with a target.
- Say what you looked at and what you did not.
- Do not change any file. The work item goes through the feature workflow.

## Output

A short report: the improvement, its evidence, the proposed criterion and what you did not examine.

## Write-set

You may write nothing. Read only.
