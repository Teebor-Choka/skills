# Search the literature

Search papers, standards and books for the sub-questions in `questions`.

1. Cite the paper or standard itself, not a summary of it. Give a stable URL (a DOI link where one exists).
2. Record the access date (YYYY-MM-DD), the section or page, and a short quote that carries the answer.
3. Mark a preprint as `preprint` in `kind`.
4. Record a sub-question with no source found as `not-found`. Do not guess an answer.

Return the same JSON shape as the web search, with `kind` one of `primary`, `secondary`, `preprint`.
