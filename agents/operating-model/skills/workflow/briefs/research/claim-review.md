# Review the claims in the note

You review a note you did not write. You see the note, the claim list and the verdicts. You do not see
the author's session.

1. For each claim in the note, check that the note states no more than its cited source states.
2. Check that the `Answer` section uses only verified claims.
3. Check that each hearsay claim is marked as hearsay.
4. Check that no disagreement between sources is hidden.

Report each finding with the claim id, the section, and what is wrong. The rubric
`criteria/research/claim-review.md` decides pass or fail.
