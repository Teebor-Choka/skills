# Look up one authoritative source

The framing chose the `lookup` route: one authoritative source answers the question.

1. Find that source. Use only hosts that the policy `research.source-allowlist` permits.
2. Record its URL, the access date (YYYY-MM-DD), and a quote for each sub-question.
3. If the source does not answer a sub-question, record it as `not-found`. Do not search further: the
   framing was wrong, and the claim review will catch the gap.

Return the same JSON shape as the web search.
