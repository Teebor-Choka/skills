# Rubric: framing

The framing passes only when every rule holds.

1. The restated question is one sentence and keeps the meaning of the original question.
2. There are 1 to 5 sub-questions, and each one is answerable from a source on its own.
3. The route is `lookup` only when the framing names one authoritative source that can answer every
   sub-question. Otherwise it is `survey`.
4. The out-of-scope list gives a reason for each entry.
5. The output contains no answer to the question.

## On a fail

Report the number of each rule that fails, the sub-question or field it concerns, and one sentence on what
is wrong. Do not rewrite the framing.
