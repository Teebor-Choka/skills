# Rubric: extracted claims

The judge reads the recorded sources and the claim list. It passes only when every rule holds.

1. Each claim is one statement of fact that one source can confirm or refute.
2. Each claim cites at least one source that the search recorded, with its URL and access date.
3. Each claim keeps the quote from its source, and the claim says no more than the quote.
4. Where two sources disagree, each position is its own claim with its own source.
5. No recorded source with a quote that answers a sub-question is left out without a reason.

## On a fail

Report the claim id or source URL, the number of each rule that fails, and one sentence on what is wrong.
The code step `claims-cited` checks rule 2 again on the recorded output; this rubric covers the rest.
