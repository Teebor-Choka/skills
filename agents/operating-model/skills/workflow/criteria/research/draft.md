# Rubric: note draft

The judge reads the draft note. It passes only when every rule holds.

1. The note has the sections `Question`, `Answer`, `Verified`, `Hearsay`, `Disagreements`, `Not verified`,
   in this order.
2. The `Answer` section has at most five sentences.
3. Every claim in the note carries its citation (URL and access date).
4. In a later round, the draft addresses each finding of the last claim review, or says why not.

## On a fail

Report the number of each rule that fails and the section it concerns, with one sentence on what is wrong.
The floors `cite-check` and `claim-review` judge citations and claims; this rubric judges the form only.
