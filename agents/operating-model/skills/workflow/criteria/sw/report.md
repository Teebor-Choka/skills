# Criteria: run report

The judge passes the work only if every rule holds. Each rule names what it is judged against.

## Pass conditions

1. Each claim in the Acceptance section matches the evidence of the run. Judged against: the output and the run's evidence.
2. The Defects section lists every defect from the review findings and the deploy verification. Judged against: the output, the review findings and the verification evidence.
3. The Not verified section names real gaps, not a restatement of what passed. Judged against: the output and the item's criteria.
4. The Metrics section quotes values the ledger holds. Judged against: the output and the run's metrics.

## On a fail

The judge reports fail and states the number of the first rule that failed and the claim that the evidence does not support. The judge adds one sentence on what would make it pass. An unreadable or missing input is a fail.
