# Criteria: final review

The judge passes the work only if every rule holds.

## Pass conditions

1. Every criterion of the item is checked against the change.
2. Each reported defect cites a file, a line and a criterion.
3. The review names what was not verified.
4. No defect was waved through because the tests pass.

## On a fail

The judge reports fail and states the number of the first rule that failed and a sample of the missed defects. The judge adds one sentence on what would make it pass.
