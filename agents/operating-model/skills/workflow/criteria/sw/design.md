# Criteria: design

The judge passes the work only if every rule holds.

## Pass conditions

1. The design names the modules and the public contract of each.
2. The design shows failure behaviour at every boundary.
3. The design reuses existing code where it can and names it.
4. The design is no larger than the acceptance tests need.

## On a fail

The judge reports fail and states the number of the first rule that failed and the design section at fault. The judge adds one sentence on what would make it pass.
