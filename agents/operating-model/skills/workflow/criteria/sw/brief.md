# Criteria: alignment brief

The judge passes the work only if every rule holds.

## Pass conditions

1. The brief names the user problem and who has it.
2. Every assumption is listed and marked confirmed or unconfirmed.
3. Every open question has a recommended default.
4. Out-of-scope items are listed with a reason.

## On a fail

The judge reports fail and states the number of the first rule that failed and the sentence of the brief that breaks it. The judge adds one sentence on what would make it pass.
