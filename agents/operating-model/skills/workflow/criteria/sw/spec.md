# Criteria: specification

The judge passes the work only if every rule holds.

## Pass conditions

1. Every criterion states a behaviour with an event, a result and a condition.
2. The five categories are all filled with specific values, not placeholders.
3. A reader could write a test for each criterion without asking a question.
4. Out-of-scope items are listed with a reason.
5. The AI-gap question has an answer: what could a passing build still get wrong?

## On a fail

The judge reports fail and states the number of the first rule that failed and the criterion id or category at fault. The judge adds one sentence on what would make it pass.
