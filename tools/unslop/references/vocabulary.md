# Vocabulary and word swaps

Pooled from the open unslop skills. Treat these as hints, not a permanent blocklist: the
flagged sense is what to fix, the literal sense is usually fine, and any single word
decays as a tell over time. Fix the habit (inflation, hype, copula avoidance), not the
token.

## AI vocabulary → plain replacement

- aforementioned → this, that
- additionally (sentence-initial) → and, also, or nothing
- align with → match, fit, support
- actionable → useful, concrete, that you can act on
- beacon of → cut
- bolster → support, strengthen (literal reinforcement is fine)
- boasts / boasts a → has
- burgeoning → growing
- bustling → cut (tourism filler)
- comprehensive → full, complete, thorough
- comprise → consist of, contain, include
- crucial / crucially → important, key, or cut
- curate / curated (outside museums) → chose, selected
- cutting-edge → modern, advanced, new
- delve / delves / delve into → explore, examine, look at, dig into
- double-edged sword → name the specific tradeoff
- elevate (metaphorical) → raise, improve
- elucidate → explain
- embark / embark on a journey → start
- empower → let, enable, give
- encompass → include
- enduring / enduring legacy → lasting
- enhance → improve, strengthen
- ever-evolving / ever-changing → cut, or name the change
- facilitate → help, enable, run
- fosters / fostering / foster → building, encouraging, creating
- functionality → features, capabilities, or a verb
- game-changer / game-changing → significant, important, major
- garner → get, earn, attract
- groundbreaking → usually cut
- harness (verb/metaphor) → use, tap, apply
- henceforth → from now on
- holistic → complete, whole
- iconic / seminal / trailblazing → usually hyperbolic; cut
- interplay → interaction
- intricate / intricacies → detailed, complex
- invaluable / noteworthy → overused; cut or be specific
- landscape (abstract) → situation, field, market, area
- leverage (verb) → use, apply
- load-bearing (metaphor) → essential, critical (literal construction is fine)
- meticulous / meticulously → careful, thorough
- multifaceted → complex, varied
- myriad (of) → many
- navigate / navigating (metaphor) → handle, address, manage
- nuanced (when meaningless) → cut
- notwithstanding → despite
- optimize (outside technical) → improve
- paradigm / paradigm shift → name the actual change
- paramount → important
- pertaining to → about
- pivotal / pivotal moment → important, key
- plethora → many
- poised to / poised for growth → cut (promotional forecast)
- realm / in the realm of → area, field, or "in"
- renowned → name why
- resonate(s) with → matters to, connects with
- revolutionize / radically transform → may help, reduces, changes
- robust (outside engineering) → strong, solid, thorough
- seamless / seamlessly → cut, or smooth
- showcase → show, demonstrate
- spearhead → lead, start, run
- state-of-the-art → cut (empty superlative)
- streamline → simplify, speed up
- tapestry / rich tapestry → cut (never)
- testament / a testament to → proof, evidence, sign
- therein / whereby → restructure the sentence
- transform / transformative (metaphor) → change
- treasure trove → cut
- ubiquitous → everywhere, common
- unparalleled / unveil / underpin → hype; cut or restate
- underscore(s) → show, highlight, prove
- utilize → use
- vibrant → cut (promotional default)
- whimsical → cut
- world-class / best-in-class / second to none → cut (empty superlative)

## Abstract metaphor and jargon nouns → concrete

Common in technical writing; replace with the plain thing.

- substrate → base, foundation, layer
- wedge → add, angle, lever, entry point
- vector → way, method
- locus / vantage / nexus → the plain place or point
- primitive (as noun) / modality / paradigm → the plain thing
- harness (metaphor) → use
- surface ("API surface") → the API, the interface
- bedrock / scaffolding (metaphor) → base, structure
- gold-plating → more than the job needs
- ratchet (metaphor) → the mechanism's real name, or "a limit that only tightens"
- evacuate (for moving code) → move out
- endgame → the last phase
- north star → the goal
- flywheel → the self-reinforcing loop (named)
- blast radius / footgun / battle-tested (performative slang) → the literal effect, risk, or "tested"

## Plain-English register (Google developer style word list)

A distinct plain-language register, not only anti-AI. Useful for docs and UI text.

- abort → stop, exit, cancel, end
- aka → also known as
- allows you to / enables you to → lets you
- and/or → _and_, or _or_ (pick one)
- as (meaning "because") → because
- click here → descriptive link text
- click on → click
- currently → usually delete
- desire → want, need
- e.g. / for instance → for example
- easy / easily / simply → delete (don't call it easy)
- etc. → such as, including
- execute (a program) → run
- in order to → to
- leverage / utilize → use
- please (in instructions) → delete
- via → through, with, from
- we / let's → you, or the imperative
- whitelist / blacklist → allowlist / denylist
- grandfathered → legacy, exempt
- guys → everyone, folks
- avoid: crazy, insane, dumb, hang (→ stop responding)
