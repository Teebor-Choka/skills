# Presentation Prep

A three-phase workflow for making a presentation. Its knowledge lives in the
**`presentation:patterns`** skill (88 patterns/antipatterns); this workflow decides
_which_ patterns to reach for at each phase and loads only that phase's reference
files. Start here; consult `presentation:patterns` as step 1 and throughout.

Work the phases in order, but loop back freely — a talk is refined under the
pressure of building and performing it (`Crucible`).

## Phase 1 — Prepare → load `presentation:patterns/references/01-prelude.md`, `02-creativity.md`

Establish the foundation before opening any slide tool (`Fourthought`):

1. **Why & who.** Nail the `Big Why` (your real motivation) and `Know Your Audience`
   (research their background, level, expectations). If this is a `Required` or
   `Proposed`/CFP talk, handle those constraints now.
2. **Generate & structure.** Ideate → capture (mind map / cards, not slides) →
   organize into an outline. Pick a shape: `Narrative Arc`, `Triad` (three points),
   or a `Talklet` series; plan `Expansion Joints` for variable length and
   `Brain Breaks` every 10–20 min.
3. **Theme.** Choose a `Unifying Visual Theme` to carry the visual channel.

Ask the user for the topic, audience, time slot, and setting if not given — these
drive every later choice.

## Phase 2 — Build → load `03-slides.md`, `04-temporal.md`, `05-demos.md`

Design the artifact, and actively avoid the slide antipatterns:

1. **Slides.** `Defy Defaults`; prefer `Vacation Photos` over text; use
   `Composite Animation`, `Analog Noise`, `Greek Chorus` where they earn their
   place; run a `Peer Review`.
2. **Time.** Add `Context Keeper` devices — `Bookends`, `Breadcrumbs`/`Intermezzi`,
   `Gradual Consistency`, `Charred Trail`, `Soft Transitions` — so the audience
   tracks progress and can't read ahead.
3. **Demos/code.** If demoing, weigh `Live Demo` (high risk) vs `Lipsync`/`Live on
Tape`; use `Emergence`, `Crawling Code`, `Traveling Highlights`.
4. **Anti-check.** Guard against `Bullet-Riddled Corpse`, `Slideuments`, `Ant
Fonts`, `Fontaholic`, `Photomaniac`, `Floodmarks`, `Cookie Cutter`,
   `Injured Outlines`. If a handout is mandatory, resolve the Slideuments tension
   with `Coda`, `Invisibility`, and `Infodeck`.

## Phase 3 — Deliver → load `06-stageprep.md`, `08-perf.md`, and skim `07-antipatterns.md`

1. **Rehearse.** `Carnegie Hall` — practice is the only real preparation.
2. **Stage prep.** `Preparation` checklist, `Stakeout` to arrive early,
   `Seeding Satisfaction`, `Posse`, `Shoeless` comfort.
3. **Perform.** `Weatherman` (never turn your back), `Breathing Room`,
   `Emotional State`, `Mentor`, `Echo Chamber` for Q&A, `Lightsaber` not
   `Laser Weapons`.
4. **Pre-flight "do-not."** Walk `07-antipatterns.md` as a checklist: no
   `Hiccup Words`, `Going Meta`, `Tower of Babble`, `Bunker`, `Negative Ignorance`,
   `Lipstick on a Pig`. Have a plan for `Hecklers`, the `Backchannel`, and a
   `Shortchanged` time cut.

## Output

Help the user produce, at minimum: the `Big Why` + audience profile, a chosen
narrative shape with an outline, a slide/build plan naming the patterns applied,
and a delivery/rehearsal checklist. Name the specific patterns you're invoking so
the user can look them up in `presentation:patterns`.
